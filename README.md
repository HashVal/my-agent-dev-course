主线暂按 10 次、每次 60 分钟安排；完整论文精讲和拓展主题单独计时。资源登记、教师选读和学习者掌握分别记录，尚未运行的实验均明确标注。

首次学习采用五道题库题加五道当前模型生成题，补齐未覆盖的基础范围；AI 判定后保存本地 `baseline-status.md`，由 Git 忽略。个人答案、成绩、诊断及项目 assessment 仅在本地保留。参考项目的源码通过上游链接查阅。

测试后按缺口进入 C00 的模型与应用、文字生成、信息与记忆、工具与验证四块讲解，再用共同案例衔接 C01。已有理解证据的部分简短回顾；未接触术语可以直接说明，无需在开课前自学完整知识清单。导学、纠错和理解检查均计入原有课内预算。
