# 独立拓展章节

这些章节是可选教学设计，均未开课、未运行实验，时间不计入主线 10 学时。每次可按 60 分钟拆分；只在选择相应方向后展开完整讲义。

另有 [论文精讲路线 P01–P06](../papers/index.md)，用于分析研究方法和证据。下列章节侧重工程能力；如果两条路线使用同一实验，复用产出、记录实际时间，不重复安排作业。所有论文的原文和版本见 [资源索引](../resources/index.md#agent-开发论文)。

<a id="x01"></a>
## X01：DeepSeek Harness 与插件生命周期

- **新增目标**：理解服务定义、提供方、消费者，以及依赖注入、事件、配置和可撤销副作用。主线只要求能实现循环，没有覆盖这些框架开发能力。
- **前置**：C04、C05、C09，基本 TypeScript；先诊断已有 Cordis 课堂内容的掌握情况。
- **材料**：[R030 源码导读](../resources/R030-deepseek-harness.md)；本地若有既往 Cordis/DSH 课程记录，可用于确定复习起点。
- **论文连接**：P05 / R035（SWE-agent）讨论接口设计；R044（SWE-bench）补充编码任务验收，不能将 DSH 视为它们的直接实现。
- **时间**：4–6 小时；前 1–2 小时追踪一次启动及一次 turn，接着 1–2 小时做最小工具插件，最后 1–2 小时检查卸载、替换与失败路径。基础补课另计。
- **实践**：在独立实验目录构建无外部副作用的插件，完成加载、调用、卸载；条件允许再替换兼容的提供方。
- **验收**：能解释无需修改消费者的条件；卸载后不存在重复工具或遗留监听；记录使用的 commit 和实际运行证据。
- **与主线关联**：C03 的工具、C04 的循环、C05 的状态在真实系统中的组织方式。它是一种工程实现方案，不是 Agent 的定义。

<a id="x02"></a>
## X02：Skills 与可复用工作流程

- **新增目标**：把任务知识、流程和辅助脚本组织为可发现、按需读取的资源，理解它与工具的区别。
- **前置**：C03、C05、C08。
- **材料**：[R010 与教学判断](../resources/anthropic-engineering.md)、[DSH skill 模块](https://github.com/deepseek-ai/deepseek-harness/blob/639ed015397290b3745d163aafe02ffee4aa3f84/packages/skill/README.md)。
- **论文连接**：R042（Voyager）的代码技能库用于讨论复用思想；自动课程和持续探索另放论文专题，SKILL.md 打包不等同于 Voyager 方法。
- **时间**：1–2 小时；用准备好的样例完成流程定义、按需加载与比较。
- **实践**：为“博客映射到课程章节”写一个最小技能，用相关与无关的输入比较无技能、常驻说明和按需加载。
- **验收**：记录触发是否正确、输出是否满足约定，以及上下文成本；发现误触发或漏触发后能解释需要修改哪一层。
- **与主线关联**：扩展 C05 的上下文组织和 C08 的效果验证；具体技能格式与加载机制按实际宿主确认。

<a id="x03"></a>
## X03：MCP 与程序化工具调用

- **新增目标**：分别理解协议接入、工具发现和代码内的工具编排；能解释 MCP、普通工具调用和 PTC 的关系。
- **前置**：C03–C05、C09，异步函数基础。
- **材料**：资源索引中的 R011、R012；DSH 的 [MCP](https://github.com/deepseek-ai/deepseek-harness/blob/639ed015397290b3745d163aafe02ffee4aa3f84/packages/mcp/README.md) 和 [PTC](https://github.com/deepseek-ai/deepseek-harness/blob/639ed015397290b3745d163aafe02ffee4aa3f84/packages/ptc-runtime/README.md) 模块。实际协议接口另查当前官方规范。
- **论文连接**：R039（CodeAct）从行动表示讨论可执行代码，与协议接入和工程运行时分开理解。
- **时间**：2–3 小时；使用准备好的本地工具服务和合成数据，完整部署分发另计。
- **实践**：给同一批数据提供直接调用和程序内聚合两条路径；只允许读取实验数据，限制调用数量与执行时间。
- **验收**：最终结果一致；记录模型可见输入量、执行开销和工具错误；工具不可用或程序报错时能够退出并报告原因。
- **与主线关联**：扩展 C03 的调用方式和 C05 的输入管理。学习 MCP 不自动意味着需要开放任意代码执行。

<a id="x04"></a>
## X04：多 Agent 的分工与协调

- **新增目标**：判断任务能否拆分，设计交接内容、结果合并和总预算，识别并行带来的重复与冲突。
- **前置**：C07、C08，并发与异常处理基础。
- **材料**：R013 为主，R018 为大型案例选读；[DSH subagent](https://github.com/deepseek-ai/deepseek-harness/blob/639ed015397290b3745d163aafe02ffee4aa3f84/packages/subagent/subagent/README.md) 为后续实现入口。
- **论文连接**：R043（AutoGen）讨论对话式协调；R041（Generative Agents）为社会模拟选读，其评价目标与任务完成不同。
- **时间**：2–3 小时；只做两个分工 Agent 的小实验。
- **实践**：对两组独立资料做查询，比较单 Agent 与分工方案；随后加入一个跨资料依赖，观察协调成本。固定模型并明确两组总预算。
- **验收**：比较覆盖率、事实依据、重复工作、延迟和调用量；任一子任务失败时，汇总结果不得假称全部完成。
- **与主线关联**：扩展 C07 的架构取舍；多 Agent 是待验证的选择，不是默认升级路线。

<a id="x05"></a>
## X05：长期任务、恢复与独立验收

- **新增目标**：设计跨会话进度、持久化状态和恢复策略，区分会话记录、循环进程与执行环境。
- **前置**：C04、C05、C08、C09。
- **材料**：R008、R014、R015；R021 可用于讨论审批，DSH session/agent-loop 可用于源码对照。
- **论文连接**：P04 / R033（Reflexion）、R040（MemGPT）与 R041（Generative Agents）分别提供反馈记忆、分层信息管理和持续行为的视角；这些机制都不自动保证进程故障后的正确恢复。
- **时间**：2–3 小时；用几分钟可完成的模拟任务验证机制，不实际运行数小时自主开发。
- **实践**：将一个任务拆成有明确验收的小步骤，在步骤间和执行后记录前分别模拟中断；使用交接文件恢复，并用独立检查判断完成情况。
- **验收**：能报告哪些工作已确认、哪些状态仍不确定；对可能重复的写操作提出并验证幂等或核对策略，不承诺仅靠日志即可实现“恰好一次”。
- **与主线关联**：扩展 C04 的运行周期、C05 的持久状态和 C08 的结果验收。先验证简单恢复，再判断是否需要初始化/执行/评估等多角色结构。
