## 选用理由

**课程来源中的内容：**工具讲义将模型请求与程序执行分开，并讲解分发、参数校验和结果关联；上下文讲义把压缩后的继续执行作为评估对象。A1 涉及共享循环、工具、上下文和 Skills；A2 以可视化 Agent 为对象，要求开发验证器、对照人工标签并分析评分错误。具体依据见上面的讲义与作业原文。

**本仓库的教学判断：**这些材料适合把已有的 ReAct、工具设计、上下文和评测知识落实到程序接口与验收产物。对已有 Agent 项目 的学习者，优先价值在于理解 SDK 代办的机制，以及补足测试和评测实现。公开课程的完整训练路线超出当前 10 学时应用开发目标。

## 与现有资料的关系及时间处理

- ReAct 论文提供循环机制，CMU 的实现材料补充工程接口；Anthropic 的工具、上下文和 eval 博客提供经验与问题视角，CMU 作业提供可观察的产物和评分流程。它们共同支持已有 C 编号，无需另开一套必修课。
- C03/C04、C05、C08/C09 各选少量讲义或作业片段，替换原有课堂中的 5–10 分钟材料讲解；验证要求并入既有实验。例如 C08 从已有案例中挑两条人工核查评分器，不额外增加一套完整 A2 作业。
- 本导读及链接初览可选，预计 20–30 分钟，为教师估计。完整视频、完整 A1/A2、模型训练和研究项目均不计入当前主线；若选择完整实践，需要根据环境与模型预算另估时间。
- 原作业涉及模型调用和 Modal 等运行环境，材料公开不代表完整实验无费用。当前仅归档和映射，没有启动实验或布置新摸底题。
