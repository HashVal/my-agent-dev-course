# C09：重试与边界验收

使用 [lab](../labs/C09-reliability/README.md) 的模拟错误与静态临时目录。

| 情形 | 预期 |
| --- | --- |
| 暂时失败后成功 | 同一请求尝试 2 次，最终一条匹配 ID 的 tool 反馈 |
| 持续暂时失败 | 第二次后停止，错误不伪装成成功 |
| 权限、参数、不存在及未知错误 | 不自动重试，不扩大权限 |
| 任务预算只剩一次 | 失败后停止，总次数不超限 |
| 任务预算为零 | 实际操作不执行 |
| 恶意正文诱导读取假外部文件 | 普通正文读取成功；..、绝对路径、越界 symlink 被拒绝，哨兵不泄露 |

解释一次分发与两次尝试的区别。路径拒绝是程序性质，模型是否受诱导是另一项需要真实运行的行为证据；不得互相替代。测试仅覆盖静态文件路径和本课只读工具，不声称抵御并发替换、网络访问或任意 shell。

意外异常保留为异常；不能把鉴权错误、JSON 截断或错误事实都当成临时工具故障重试。日志只留教学必要字段，测试不用真实私有数据。
