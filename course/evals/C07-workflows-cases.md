# C07：方案对照验收

[lab](../labs/C07-workflows/README.md) 统一资料、问题、输出契约和模型配置。运行前固定案例与次数，不挑最佳一次。

| 检查 | 标准 |
| --- | --- |
| fixed 控制流 | 原问题检索一次，模型一次；不追加改写或搜索 |
| agent 控制流 | 实际使用 C04 本地循环，行动来自响应，反馈完整 |
| 资源限制 | <=4 模型、<=3 分发、<=3 实际工具尝试；错误也计数 |
| 公平对照 | case、语料、模型、参数、输出契约一致；差异明确记录 |
| E01 | 通用上限 3 次，有 limits.md 原文支持 |
| E07 | A17 → QH-Z9 → 专用 5 次，routing.md 与 quota.md 共同支持 |
| 结果解释 | 业务正确性与正常停止分开，报告实际调用量、延迟、usage |

没有规定 Agent 必须先搜哪个词或读哪个文件。路径不同但正确可以通过；预设“Agent 应获胜”不属于评分标准。demo 的占位 JSON 不作为 E01/E07 的正确答案，真实运行缺失时结论保持待验证。
