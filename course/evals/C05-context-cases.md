# C05：上下文选择验收

输入来自 [lab](../labs/C05-context/README.md) 的虚构记录。以下是公开判断依据，不是个人成绩。

| 检查 | 应观察到什么 | 不通过或待验证 |
| --- | --- | --- |
| 短内容、错误结果 | 独立副本，字段与内容不变 | 原始对象被修改、错误信息被截断 |
| 长内容、奇偶额度 | 首尾长度符合契约，标记与原长明确 | 把截断结果称为全文，丢失 file |
| 消息关联 | 角色与调用 ID 保持，原日志完整 | 孤立 tool 消息或原日志同步变短 |
| 中部证据反例 | 完整输入有编号，裁剪输入无编号 | 只报节省字符而不说明信息损失 |
| 模型对照（接口可用时） | 分别保存实际输入、响应、usage；核查引用 | 模拟冒充真实，猜中即算有证据 |

核心解释：上下文变短不会退还执行额度；磁盘日志不会自动进入模型；字符数不是 token 或账单。用“裁剪后重读仍被裁剪”的新情形检查策略局限。未执行真实对照时，只能确认输入与程序行为，不声称模型效果或费用改善。

实际记录仅存 `.local/`。真人能否依据讲义完成解释与实验，按 [试读办法](lesson-readthrough.md) 另行记录。
