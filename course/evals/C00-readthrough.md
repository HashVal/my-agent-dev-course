# C00：试读与衔接核查

本文件用于核查 [C00 导学](../lessons/C00-llm-foundations.md) 是否帮助基础较弱的学习者进入 C01。它不是第二套摸底试卷，也不替代代码实践。讲义、题库与流程均可由作者检查；学习效果还需要真实学习者的回答和操作。

## 理解检查口径

在对应块结束时使用讲义中的新情形，先让学习者解释，再按需提示。这里的判断依据用于复核；若已读过依据，记录条件，不声称独立回答。

| 对应内容与新情形 | 要观察的解释 | 仍需补充的信号 |
| --- | --- | --- |
| 一：读取会议记录后只发送“读取成功” | 原文还在程序中，未进入请求；应传入相关内容才能依据它总结 | 把读取成功、文件存在直接当作模型收到全文 |
| 二：回答第 3 个 token 与尚未生成的第 6 个 token | 区分已提供提示词与未来输出；说明逐步生成，核对事实仍需外部依据 | 混淆两段序列，或认为 attention 会读取未提供的信息 |
| 三：排课文件已更新，请求仍带昨天文本 | 优先更新本次输入中的资料；答对不证明权重更新 | 认为磁盘修改自动进入所有请求，或每次纠正都是训练 |
| 四：工具报文件不存在，模型却声称报告显示测试通过 | 保留工具错误，不能据模型自述接受结论；需要报告或实际测试结果 | 把读取失败等同于资料没有答案，或把流畅回答当证据 |
| 衔接 C01：limits.md 问答与费用问题 | 能画输入路径，指出规则不包含费用证据，并结合资料规模和任务要求解释方案选择 | 只会背四种方案名称，不能说明谁决定下一步或为何增加工具 |

每项只记“能独立解释 / 提示后能解释 / 仍有困难 / 未检查”，附具体依据，不另给总分。未能解释时回到相应例子补充；需要更深的 token、向量或 attention 检查时，从学习者刚暴露的缺口选一个小问题，不自动叠加一套题。讲解与复核使用 [大纲](../syllabus.md#课时如何复用) 的课内预算。

## 诊断流程的作者走查

下面是**人工构造的流程案例**，用于检查规则是否可执行，不能充当真人试读或实际答题记录。

| 虚构输入情况 | 预期教学选择 | 不应作出的推断 |
| --- | --- | --- |
| B02/B05 中明确表示未接触 token、embedding 和 attention | 记录具体考点陌生，进入第二块连贯讲解；先核对第一块所需的信息路径认识 | 不能从术语陌生推断不会 Python，或仅给答案后直接进 C01 |
| 能解释生成，但认为“保存偏好文件就是更新权重” | 定位第三块的局部误解，用操作对照纠正，再用排课情形复核 | 不必重讲所有四块；不覆盖首次判断 |
| B05 未作答，其他题表现充分 | B05 对应细项仍为未检查，先澄清原因或用块内检查定位 | 不把高总分当作 Transformer 基础已掌握 |
| 基础概念解释充分，B10 不能追踪字典访问 | C00 简短衔接；在编码实验前补充 Python 实操 | 不用完整 C00 替代编程补练 |
| 已有完整适用基线与复核记录 | 读取下一步，复用共同案例进入 C01 或原有进度 | 不重新组十题，也不因新讲义发布而强制全部重学 |
| 题干把提示词与输出的 token 编号混用 | 先澄清序列；若已讲出机制答案，分别记初次表现和有辅助回答 | 不把题意歧义判成概念错误，不把提示后回答算作独立初测 |

## 初学者试读办法

适合的试读者是会基本 Python、尚未系统学习 LLM 的人。先读取其适用基线；没有基线时沿用首次十题流程，不另加招募测试。明确哪些块需要完整学习，哪些只回顾。

试读按正式教学节奏进行：每块记录卡住的词句，使用上表的新情形检查理解，最后复用资料问答案例进入 C01 开头。观察能否解释机制与方案之间的关系，不以“看起来懂了”或满意度代替证据。所需时间算入该学习者 C00/C01 的课内安排；只有整理材料反馈约需额外 5–10 分钟，属于自愿参与的可选反馈。

个人原始回答、首次判定、讲解内容及复核结果追加到本地 baseline-status.md；具体试读反馈可存入 Git 忽略的 `.local/C00-readthrough/`，不能放进公共进度。建议记录：

| 记录项 | 内容 |
| --- | --- |
| 条件 | 日期、讲义版本、已有基础、选学块、是否提前看过依据 |
| 首次证据 | 本地基线的题号及具体考点；原始答案与判定保留原处 |
| 讲解与卡点 | 阅读到哪里、实际讲解或提示、卡住的词句及原因 |
| 新情形复核 | 实际题干、原始回答、是否有提示、判定依据与尚存困难 |
| 衔接 | 画出的信息路径、方案选择理由、需要接着补充的点 |
| 时间 | 实际耗时；未知则写未知，不从文件时间戳推断 |

公共记录只汇总材料应怎样修改及验证状态，不复制个人成绩或诊断。一次试读只能发现局部可读性问题；不能推断所有初学者均能在预计时间内完成。
