# C06：检索与来源验收

使用 [固定教学语料](../labs/C06-retrieval/README.md)，不把评测文件放进检索根目录。

| 案例 | 核查依据 |
| --- | --- |
| 英文/编号及中文词项 | 分数为不同共享词项数量，不是出现次数或概率 |
| 同分排序 | 文件名与起始行号决定稳定顺序；输入文档不变 |
| 来源核对 | quote 等于指定文件首尾行之间的原文，title 单独保留 |
| 空匹配 | 返回 []，不任意补文档 |
| T01 组合问题 | 检查任务记录和通用额度是否同时命中；未命中也如实记录 |
| A17 规则适用范围 | 区分对象映射和额度证据；专用规则不能直接套到 T01 |
| 错误参数 | 空白/超长查询、bool/越界 top_k 被拒绝 |

通过函数检查不等于检索能覆盖所有自然语言表达。复盘应给出一例“库里有证据但没命中”和一例“证据到了却可能答错”的原因分析；可用人工构造输入，不虚构实际模型运行。
