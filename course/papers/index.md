# 可选论文精讲路线

建立日期：2026-10-22。状态：路线与练习设计，未开课、未运行实验。原文链接、作者及版本见 [资源索引](../resources/index.md#agent-开发论文)，15 篇的课程映射见 [论文导读](../resources/papers.md)。

## 与主线课程的关系

主线 C01–C10 完成最小 Agent 及评测，课内只选取必要的论文思想。论文线进一步回答“为什么这样设计、实验支持了什么、在哪些条件下可能不成立”。具备前置知识后可以穿插学习，不要求先读完全部论文，也不默认执行整条路线。

P 编号标识精讲单元，R 编号标识资源。例如 P01 使用 R031 / ReAct；编号与 C、X 章节互不替代。同一论文只登记一份资源，精讲可关联多个章节。

## 时间与课堂形式

优先的 P01–P06 各暂估 **2 次 × 60 分钟，共 12 学时**，单独计入学习预算。若只选择一个单元，则只增加对应的两次课。每次仍为一学时，学时长度尚待校准。

| 课次 | 60 分钟安排 | 当次产出 |
| --- | --- | --- |
| 第一次：问题与方法 | 10 分钟诊断前置知识；15 分钟问题、假设和基线；20 分钟方法图与最小例子；10 分钟边界或反例；5 分钟回顾。 | 一张问题卡、一张方法图或伪代码；能解释与原有方案的差异。 |
| 第二次：证据与验证 | 15 分钟核对实验设置和指标；15 分钟阅读关键对照/消融；20 分钟准备好骨架的缩小版练习；10 分钟复盘。 | 一张证据卡、一份实际观察或未运行说明，以及仍不能支持的结论。 |

这是引导式关键内容精讲的预算，不承诺逐段讲完正文与附录，也不包含完整训练或大规模基准复现。无需强制预读；课堂使用的原文选段、图表和实验骨架由老师备课准备。完整自读、数学补课、环境安装和完整复现若有需要，应显式估时并调整安排。

缩小版练习用于理解机制，不能标为“复现论文结果”。若使用录制轨迹或模拟分数，明确标注来源及性质；没有实际模型调用时不声称验证了模型收益。

## 优先单元

<a id="p01"></a>
### P01：ReAct — 让行动受环境反馈影响

- **资源与前置**：R031；C03、C04。R037 / CoT 可用一小段补充背景，不要求另读全文。
- **第一次课**：从一次无法仅凭已有信息解决的查询开始，区分推理、行动和环境观察；画出信息何时进入下一步。
- **第二次课**：核对论文的对照条件；在同模型、工具与预算下，比较预先规划和逐步根据反馈行动。使用会改变下一步选择的工具结果。
- **验收**：能指出一次由真实观察引起的策略变化，并解释失败时应检查模型、工具还是循环。一次成功不等于证明普遍优于固定流程。
- **后续连接**：C04 的最小循环及 DSH 的 turn/step；不要求复刻固定的文本标签格式。

<a id="p02"></a>
### P02：Toolformer — 工具使用能力如何学到

- **资源与前置**：R032；C02、C03，能够区分模型训练和推理。若尚不理解训练目标，先安排补课。
- **第一次课**：阅读论文如何构造和选择工具调用数据，标出哪一步更新权重，哪一步只是使用已学能力。
- **第二次课**：检查对照与筛选方法的证据；用准备好的候选调用和说明性分数走一遍选择过程，讨论有用、无用和失败调用。示例分数若为模拟必须标明。
- **验收**：能解释训练样例为何保留或丢弃，以及为何普通函数调用演示不能验证论文的训练效果。
- **范围**：本单元不训练完整模型；若决定做训练复现，另估数据、算力和时间。连接 C03 与 R004 的工具接口设计。

<a id="p03"></a>
### P03：RAG — 检索与生成如何协作

- **资源与前置**：R034；C02、C06。检索排序与模型训练细节按背景补充。
- **第一次课**：画出检索器、外部文档和生成器的数据流；对照原文的方法，注明与课堂关键词检索的差别。
- **第二次课**：阅读知识密集任务中的实验及基线；在小资料集里分别制造检索失败与生成失败，检查证据及回答。
- **验收**：能判断一个错误发生在检索还是生成环节，说明加入外部资料后仍可能出错的原因。
- **后续连接**：C06、R009 / Contextual Retrieval；课堂机制演示不等于原始模型训练与评测复现。

<a id="p04"></a>
### P04：Reflexion — 反馈能否改善下一次尝试

- **资源与前置**：R033；C04、C05、C08。
- **第一次课**：区分任务执行、反馈、反思文本和跨尝试记忆；明确该方法不通过更新权重来学习。
- **第二次课**：核对反馈来源及相应实验；用同一失败案例比较直接重试和带反馈重试，控制尝试次数与总预算，再加入一条错误反馈。
- **验收**：报告反馈是否改变了行为、是否真的改善外部结果；不能只因生成了反思文字就认定发生改进。
- **后续连接**：C05、C07、X05；区分反思内容与可验证的进度记录。

<a id="p05"></a>
### P05：SWE-agent — 工具接口也是系统设计

- **资源与前置**：R035；C03、C04、C08，具备阅读小程序和测试的能力。R044 / SWE-bench 只作为必要评测背景。
- **第一次课**：分析文件定位、查看、编辑与执行接口的设计；把方法落实到模型实际获得的观察和可以做的动作。
- **第二次课**：核对论文的接口比较；在隔离的小型代码练习中，对同一修复任务比较两种接口，检查结果、无效操作和开销。
- **验收**：能把观察到的行为差异联系到具体接口，同时指出模型或预算差异可能造成的混淆；用测试检查修复。
- **后续连接**：X01 的 DSH 工具流水线。不安装完整 SWE-bench 环境，不把一个小修复的成功外推到基准成绩。

<a id="p06"></a>
### P06：τ-bench — 成功一次与稳定成功

- **资源与前置**：R036；C03、C08、C09。R045 / AgentBench 为跨环境评测的可选背景。
- **第一次课**：拆解用户交互、领域规则、工具和最终数据库状态；说明评分为何不能只看最后一句回复。
- **第二次课**：阅读评测设置与重复运行指标；用小型模拟订单数据检查结果与规则，重复少量案例，区分“至少一次成功”与“每次均成功”。
- **验收**：能识别口头完成但状态错误的案例；明确 pass@k 与 pass^k 的不同目标；报告实际样本数和小样本局限。
- **后续连接**：C08 的 outcome 与 C09 的约束。模拟课堂任务不等于原始基准复现。

## 其余论文如何选讲

以下是第二轮候选，不计入上述 12 学时。选中后再分配独立 P 编号并展开讲义。每篇关键内容精讲可先估 1–2 学时；需要补基础、实现或完整复现时重新估算。

| 方向 | 候选资源 | 与现有课程的关系 |
| --- | --- | --- |
| 推理与搜索 | R037 / CoT、R038 / Tree of Thoughts | C02、C07；CoT 可仅作为 P01 背景，ToT 的搜索与预算比较可独立讲。 |
| 行动表示 | R039 / CodeAct | X03；对照 MCP/PTC 的工程实现，区分协议与行动表示。 |
| 记忆与持续行为 | R040 / MemGPT、R041 / Generative Agents | C05、X05；分别讨论信息管理与行为评价，不把两篇合成同一种记忆方案。 |
| 技能积累与开放式学习 | R042 / Voyager | 与 X02、X05 部分相关；自动课程与持续探索另立论文专题，不强行纳入技能打包课程。 |
| 多 Agent 协作 | R043 / AutoGen | X04；可复用双 Agent 练习，阅读原论文不等于学习当前 SDK。 |
| 编码与跨环境评测 | R044 / SWE-bench、R045 / AgentBench | C08；可作为 P05/P06 背景，也可分别深入任务构造和评测局限。 |

## 每个单元保留的记录

正式备课或开课时再建立 `P01-<topic>.md` 等讲义，不提前生成空文件。记录论文版本、原文定位、学习者回答、方法图、实验条件和实际结果，并更新 [学习进度](../progress.md)。

证据卡至少回答：作者的主张是什么、比较对象是什么、数据和指标是什么、哪项实验支持该主张、还有哪些替代解释、我们的练习实际验证了什么。未知或未做的项目如实标注。
